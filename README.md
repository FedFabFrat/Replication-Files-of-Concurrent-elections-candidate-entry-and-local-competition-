# Replication Package — *Concurrent Elections, Candidate Entry, and Local Competition*

**Author:** Federico Fabio Frattini  
**Journal:** Public Choice

---

## Overview

This repository contains the datasets and analysis code needed to reproduce all tables and figures in the paper. Raw data are included so that replicators can run the full pipeline from scratch, starting from original sources.

## How to Replicate

### Step 1 — Set the root directory

Open `master.do` and update the global on this line:

```stata
global maindir "/path/to/replication_package"
```

All other paths (`$output`, `$data_controls`, `$data_elezioni`, `$maps`) are derived from `$maindir` automatically. No other path changes are needed.

### Step 2 — Install Stata packages

Run the install commands in the table above. Only needed once per machine.

### Step 3 — Create the output directory

Create an empty `output/` folder at the replication package root. All tables (`.tex`) and figures (`.pdf`, `.png`) are written there.

### Step 4 — Run the Stata master do-file

```stata
do "/path/to/replication_package/master.do"
```

`master.do` runs in order:
1. **Data generation** (Sections 2.1–2.4): builds `elections_data_0525.dta`, `controls_9111.dta`, `mayors_chars_0525.dta`, and `final_data.dta` from raw inputs.
2. **Cleanup** (Section 2.5): erases intermediate files generated during Step 1 so they do not accumulate across runs.
3. **Analysis** (Section 3): one do-file per exhibit, producing all tables and figures.

### Step 5 — Produce Figure A1 (geographic map, R only)

`FigureA1.do` saves `data/maps/nlse.dta` as a by-product. After `master.do` completes, open R and run:

```r
source("data/maps/maps.R")
```

Update the `maps` path variable at the top of `maps.R` to point to `data/maps/` within the replication package before running.

## Main Dataset: `data/final_data.dta`

Panel dataset at the municipality × election level. Unit of observation: municipality (`codcom`) × election year (`anno`), covering 6,685 municipalities in Italy's 15 ordinary-statute regions, 1991–2019.

**Key variables:**

| Variable | Description |
|----------|-------------|
| `codcom` | ISTAT municipality code |
| `anno` | Election year |
| `ele_date` | Election date (Stata date format) |
| `codreg` / `codpro` | ISTAT region / province code |
| `nlse_did` | Treatment indicator: DiD variable for exposure to national–local concurrent elections (NLCE); all post-treatment elections coded as treated |
| `n_cand` | Total number of mayoral candidates |
| `n_natp` | Number of candidates from nationally-established parties |
| `n_civp` | Number of candidates from independent (civic) parties |
| `sh_votes_natp_1st` | Vote share of the leading nationally-established party candidate |
| `sh_votes_civp_1st` | Vote share of the leading independent party candidate |
| `natwin` / `civwin` | Win indicator for nationally-established / independent candidate |
| `inv_hhi` | Inverse Herfindahl–Hirschman Political Competition (HHPC) index |
| `ever_natp_1` / `ever_civp_1` | =1 if municipality ever had a nationally-established / independent party candidate |

**Sample restriction used throughout:** `ever_natp_1 == 1 & ever_civp_1 == 1` — municipalities that experienced mixed competition (nationally-established vs. independent) at least once (~5,790 municipalities).

## Notes

- **Special statute regions excluded**: Trentino-Alto Adige, Friuli-Venezia Giulia, Valle d'Aosta, Sicily, and Sardinia are excluded throughout (different electoral rules).
- **Concurrent election dates**: Only two in the sample — 13 May 2001 and 13 April 2008.
- **`bilanci_mngd_2.dta`** is provided as a pre-built file; no data management do-file for it is included in the replication package.
- **Figure A1** has no Stata output; `FigureA1.do` only generates the input dataset (`nlse.dta`) for `maps.R`.
